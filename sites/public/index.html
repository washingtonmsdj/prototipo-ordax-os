O PRODUTO

Um sistema feito para ser usado, não administrado.

01

OrdaX Creator

O caminho público planejado para criar a mídia OrdaX sem exigir terminal, Git, partições ou compilação.

02

Surface

Uma experiência visual única para abrir apps, arquivos, rede, ajustes e informações do sistema.

03

Componentes independentes

Apps e serviços evoluem separadamente sempre que uma mudança não precisa substituir a Base inteira.

04

Conhecido-bom

Mudanças de Base usam staging e health para evitar que uma atualização defeituosa destrua o último estado funcional.

ATUALIZAÇÕES

Evoluir deve ser simples.
Voltar também.

O caminho planejado para o OrdaX público combina atualizações oficiais e recuperação. Para você continuar trabalhando, com clareza sobre o que mudou.

Release verificada

Downloads oficiais com versão, tamanho e informações de integridade para consultar antes de instalar.

Atualize só o necessário

Quando possível, apps e componentes recebem sua própria evolução sem transformar toda mudança em reinstalação do sistema.

Base com rollback

A recuperação é parte do projeto: preservar uma versão funcional quando uma atualização crítica não puder ser concluída.

ORDA X CREATOR

Do download ao OrdaX, rodando diretamente pelo pendrive.

O Creator seleciona uma mídia compatível, prepara o OrdaX e verifica a gravação. No MVP, o sistema é inicializado e utilizado pelo USB; instalação permanente em SSD/NVMe/HD fica para uma fase pós-MVP.

1Baixar

Obter somente uma release pública autorizada.

2Criar

Escolher o USB e deixar o Creator preparar a mídia.

3Iniciar

Bootar um hardware suportado e continuar na Surface OrdaX.

4Usar

Continuar trabalhando diretamente pelo USB. O disco interno não é alterado pelo MVP.
